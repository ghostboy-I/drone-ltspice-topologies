# CFD results

Summaries of the OpenFOAM runs: one folder per project, one subfolder per case. Each case folder holds a README with the
key numbers and hand checks, the summary JSON, the plots and a force history CSV. Raw solver output (time folders, processor
folders, meshes) is not kept here: it lives under each project's `cfd.run_root` and is regenerated by that project's scripts.

| Folder | Project | Written by |
|---|---|---|
| [01_54x18_Composite/](01_54x18_Composite/) | 54″ × 18″ composite prop: Caradonna–Tung validation of the CFD method | `Props/01_54x18_Composite/src/ct_export.py` |
| [02_Toroidal_Rotor/](02_Toroidal_Rotor/) | Toroidal rotor (`toroid_prelim`, done) and its 2-blade 54x18 reference on the same mesh recipe (`reference_prelim`, done); optimisation candidate `toroid_opt1_prelim` (done) | `Props/02_Toroidal_Rotor/src/toroid.py post <rotor>` |
