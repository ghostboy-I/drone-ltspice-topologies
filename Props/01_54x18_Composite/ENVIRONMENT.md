## OpenFOAM fork note

This is OpenFOAM **Foundation v13**, so cases use `foamRun` with solver modules (`incompressibleFluid`, `fluid`, `shockFluid`), `MRFProperties`/`fvModels`-style setup and `mover`-based mesh motion with NCC (non-conformal coupling) rather than ESI's `cyclicAMI` sliding mesh. The brief's solver names (`simpleFoam`, `pimpleFoam`, `rhoSimpleFoam`) map to those modules; ESI syntax will not be mixed in. The `incompressibleFluid/propeller`, `mixerSRF` and `rotorDisk` tutorials are the reference cases.
